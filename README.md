## 🖥️ Using custom-sol-address
Once the application is running, you'll see a user-friendly interface:

1. **Input Your Vanity Text**
   In the provided text box, enter the letters or numbers you want to include in your address.

2. **Generate Address**
   Click the "Generate" button. The application will work to create a valid Solana address with your chosen vanity text.

3. **Copy the Address**
   After it generates, simply click the "Copy" button to copy your new address to the clipboard for easy use.

4. **Check Validity**
   You can paste your address into a Solana wallet to check if it is valid and functions properly.
